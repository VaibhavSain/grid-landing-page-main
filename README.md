# Grid Landing Page

A modern and responsive landing page built with a clean **grid-based layout**. This project focuses on creating a visually appealing interface with responsive design and a simple, maintainable structure.

## 🚀 Features

* 📱 Fully responsive design
* 🎨 Modern and clean UI
* 🧩 Grid-based layout
* ⚡ Fast and lightweight
* 🌐 Cross-browser compatible
* 💻 Easy to customize

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
grid-landing-page-main/
│
├── index.html
├── style.css
├── script.js
└── assets/
```

## 🔧 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/VaibhavSain/grid-landing-page-main.git
```

### 2. Navigate to the project

```bash
cd grid-landing-page-main
```

### 3. Run the project

Open `index.html` directly in your browser, or use **Live Server** in VS Code.
